# Python

Python is the language this curriculum uses, for two reasons: it reads almost like English, and it's what the AI ecosystem is built on. Nearly every machine learning library — PyTorch, TensorFlow, scikit-learn — is Python-first.

This section teaches **enough Python to write scripts that do real things.** It is not a language course.

## What that means

You will not find a chapter on object-oriented design, decorators, generators, or metaclasses here. Those are real parts of Python and you'll meet them eventually — but they are not what stops a beginner from writing a script that reads a file and produces a report.

What stops people is not knowing how to run the thing, not understanding why `"5" + 5` fails, and not being able to read a traceback. That's what this section covers.

## Before you start

This section assumes the earlier ones:

- **A terminal** you can use — [Terminal Basics](/tutorials/terminal-basics)
- **A virtual environment** set up — [Virtual Environments](/tutorials/virtual-environments)
- **`uv` installed** — [uv](/tutorials/package-managers/uv)

That last one matters. Every example here assumes you're running code inside a project environment, not typing into a global Python. If you skipped that, go back — it's the difference between "this works" and "why is this broken on my machine."

## How to use it

Type every example. Do not read this like an article.

<Callout variant="warning" title="Reading code is not learning code">

Watching someone else type is not how you learn to type. Reading Python and thinking "yes, that makes sense" feels like progress, and then you sit down in front of a blank file and nothing comes out.

The `CheckYourself` boxes in this section are not optional. Answer them in your head, or better, in a file, before revealing.

</Callout>

If something doesn't work, that's the normal state of writing code. [Errors and Debugging](/tutorials/python/errors-and-debugging) exists for exactly that reason — and reading errors is the highest-return skill in this entire curriculum.
