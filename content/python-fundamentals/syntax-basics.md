# Python Syntax Basics

Python uses indentation rather than curly braces or semicolons to define blocks of code.

## Variables and Types

```python
count = 5
label = "sensors"
pi = 3.14159
is_active = True
```

## Conditionals and Loops

```python
if count > 3:
    print("Above threshold")
else:
    print("Below threshold")

for i in range(count):
    print(i)
```

## Functions

```python
def add(a, b):
    return a + b
```
