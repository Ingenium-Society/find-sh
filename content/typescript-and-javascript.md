# TypeScript & JavaScript

JavaScript is the programming language of the web. TypeScript is JavaScript with static types added on top, catching bugs in your editor before you even run your code.

```typescript
const greeting: string = "Hello, Ingenium";
console.log(greeting);
```

## Why TypeScript?

- **Autocompletion & Docs** — your editor knows what properties objects have.
- **Safe Refactoring** — rename a field across 20 files without breaking things silently.
- **Industry Standard** — powering modern web apps, Node.js backends, and Next.js sites like this one.

## Running TypeScript

Node.js executes JavaScript/TypeScript runtime environments. You can run TS files directly with modern runtimes like Node or Bun:

```bash
node index.ts
```
