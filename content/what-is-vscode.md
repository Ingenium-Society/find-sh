# What is VS Code?

Visual Studio Code (VS Code) is a lightweight but powerful source code editor developed by Microsoft. It runs on your desktop and is available for Windows, macOS, and Linux.

## Key Features

- **Extensions** — thousands of plugins for themes, linters, Git integration, and language support.
- **Integrated Terminal** — run commands without leaving your editor.
- **Git Integration** — stage, commit, and push changes directly from the source control tab.

## Essential Shortcuts

- `Ctrl + P` (or `Cmd + P` on Mac) — Quick open files by name.
- `Ctrl + Shift + F` — Search across all files in the project workspace.
- `Ctrl + ~` — Toggle integrated terminal.
