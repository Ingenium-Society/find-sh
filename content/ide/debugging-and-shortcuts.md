# Debugging & Keyboard Shortcuts

Mastering your editor's debugging tools and keyboard shortcuts will drastically accelerate your development workflow.

## Essential Keyboard Shortcuts (macOS / Windows)

| Action | macOS | Windows / Linux |
|---|---|---|
| Quick Open File | `Cmd + P` | `Ctrl + P` |
| Command Palette | `Cmd + Shift + P` | `Ctrl + Shift + P` |
| Global Search | `Cmd + Shift + F` | `Ctrl + Shift + F` |
| Toggle Terminal | `Ctrl + ~` | `Ctrl + ~` |

## Debugging in VS Code

Instead of relying solely on `console.log()` or `print()` statements:
1. Click to the left of any line number to set a **breakpoint** (red dot).
2. Run your code in Debug mode (`F5`).
3. Inspect local variables, call stacks, and step through execution line by line (`F10` over, `F11` into).
