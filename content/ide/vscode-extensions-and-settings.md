# VS Code Extensions & Settings

Visual Studio Code is powerful out of the box, but extensions and workspace settings turn it into a powerhouse.

## Essential Extensions for Club Projects

1. **Prettier** — Code formatter that keeps indentation and style consistent across team members.
2. **ESLint** — Finds and fixes problems in your JavaScript/TypeScript code.
3. **GitLens** — Supercharges built-in Git capabilities to show blame annotations and commit history inline.
4. **Python (Microsoft)** — Linting, debugging, and Jupyter notebook support for Python.

## Recommended Workspace Settings (`.vscode/settings.json`)

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.tabSize": 2
}
```
