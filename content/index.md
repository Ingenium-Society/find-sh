# Welcome to find.sh

This is the Software & AI division's tutorial hub — practical, no-fluff material for club projects. No account, no sign-in, just browse the folder tree on the left and click into whatever you need.

## What's here

- **Python Fundamentals** — syntax, environments, project structure, dependencies
- **Git Fundamentals** — commits, branching, undoing mistakes, collaborating with remotes
- **Command Line Basics** — bash/zsh and PowerShell, side by side
- **TypeScript & JavaScript** — the language, and how to actually run it
- **Working with APIs** — calling APIs from Python and JS, and keeping your keys safe

## How to use this site

Pick a topic from the sidebar. Each folder has an overview page, followed by focused, single-topic pages you can jump straight to — no need to read start to finish.

## Something missing?

This site is community-maintained. If a topic you need isn't here yet, or something's out of date, open a pull request on our [GitHub Repository](https://github.com/Ingenium-Society/find-sh) — see the Git Fundamentals section for how contributing works.
