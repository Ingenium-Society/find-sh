# Working with APIs

APIs let your code talk to other services over the internet — weather data, school systems, third-party tools, or an API you build yourself for a club project. This section covers the concept once, since it applies the same way regardless of which language you're using, followed by language-specific tutorials for actually writing the code.

## What's in this section

- **What is an API?** — the client/server request-response cycle, HTTP methods, JSON, and status codes.
- **Calling APIs in Python** — using the `requests` library.
- **Calling APIs in JavaScript** — using built-in `fetch`.
- **API Keys and Secrets** — how to handle credentials safely, especially important since this project's repo is public on GitHub.

Start with "What is an API?" if you haven't worked with one before — the language-specific pages assume you already know the concepts it covers.
