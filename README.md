# Ingenium Software & AI Tutorials

Official learning materials, reference guides, and documentation for the Software & AI division of **Ingenium Society Club**.

Members can browse practical, code-focused tutorials through a file-explorer-style interface (featuring a collapsible folder tree and rendered markdown previews).

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Content & Contributions

All tutorial markdown lives inside `/content`. Updates are made by committing markdown files directly to the repository.
